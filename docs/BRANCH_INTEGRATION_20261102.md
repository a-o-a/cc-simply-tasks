# 브랜치 통합 — 2026-11-02

최신 master `a96958e`에 `codex/release-readiness` (`f168b8f`)를 실제 merge로 통합했다. `refactor/maintenance-hardening` (`e4a35de`)은 release-readiness의 조상이므로 함께 포함된다. 두 작업 브랜치를 삭제해도 기존 커밋은 master의 조상으로 유지된다.

## 충돌 해결 기준

- 작업 브랜치의 요청 Origin/Referer 검사, JSON 256 KiB 제한, 활성 팀원 관계 검증, 감사 diff 정규화, 파일 다운로드·백업 보호를 보존했다.
- master의 TODO `expectedUpdatedAt` 충돌 검사와 부모 버전의 단조 증가, 트랜잭션 안에서의 저장 응답 생성, 오래된 활동 더 보기와 등록자 조회를 결합했다.
- 간트 날짜 헤더·배경은 화면과 앞뒤 4열만 렌더링한다. 기존 휴일 조회 오류 재시도, KST 경계와 전체 스크롤 폭을 유지했다.
- 저장·삭제 중 동기 ref 잠금, 초안 보존과 인라인 오류, 휴일 편집, 모바일 티켓 입력·일정 폼을 통합했다.
- 작업 검색은 한글 조합을 보존하며 250ms 지연 조회와 Enter/blur 조회를 지원한다. 오래된 응답 취소와 최신 필터 반영은 유지한다.
- 차콜 테마, 5px 필드 간격, 모바일 메뉴, 테이블의 이전/다음 페이지 방식을 유지했다. 칸반·간트는 제한된 API 페이지를 끝까지 읽는다.
- Chromium의 HTML pattern 오류를 수정하고 팀원 선택 버튼에 이름을 지정했다. 서비스명 최초 조회가 끝나 초안에 반영되기 전 입력을 잠가 초기 조회와 빠른 입력의 경합을 막았다.

## API·운영 계약

- 목록은 기본 50건, 최대 200건이다. 정렬값을 담은 `page:` 커서는 기준 행이 삭제돼도 이어 읽는다. 기존 ID 커서도 지원하며 사라지거나 필터에서 제외된 ID는 복구 가능한 400으로 응답한다. 필터·정렬 변경 시 클라이언트가 페이지를 초기화한다.
- TODO 드로어는 `expectedUpdatedAt`을 보내며 충돌 시 409와 함께 초안을 보존한다. 이 필드를 생략하는 기존 API 요청과 다른 엔티티 편집의 마지막 저장 정책은 유지한다.
- 백업 생성 응답은 서버 절대 경로 대신 파일 이름을 반환한다. 스냅샷·스트림·동시 백업·심볼릭 링크 보호를 유지한다.
- 실제 `.env`·`.env.production`은 추적에서 제외하고 예시 파일을 제공한다. 배포 전 기존 환경 파일을 별도로 보관하고, 파일이 없는 새 환경에서만 예시를 복사한다.
- Node 22.23.3, Next.js 16.4.2, ESLint 10, PostCSS 8.5.31을 유지하고 master의 Radix·Drizzle 0.45.4·Zod 4.6.7과 Playwright 1.64.1 검사 도구를 결합했다.
- DB 스키마·migration·빈 DB 템플릿의 변경은 없다. 검수는 임시 DB를 사용했다.
